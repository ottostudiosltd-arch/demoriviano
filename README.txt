RIVIANO STUDIO — ANIMATED, MOBILE-READY DEMO
Open index.html in a browser to preview (works offline except Google Fonts).

Animations included
- Hero load sequence: headline lines rise, photo wipes in, blob + sticker pop in
- Gentle parallax on the hero photo, floating sticker, morphing blush shape
- Scrolling photo ribbon (pauses on hover)
- Staggered scroll reveals on collection cards, image wipe in About
- Card hover: zoom, underline draw, arrow tilt
- Sticky header that shrinks on scroll, scroll progress bar
- Animated mobile menu, pulsing enquiry button
- Respects "reduce motion" system setting; works without JavaScript

Before launch, confirm product names, availability, prices, delivery terms and the preferred WhatsApp/contact destination. Obtain permission to use all photos.
This is a static frontend demo; it has no checkout, payment, order management or backend.
